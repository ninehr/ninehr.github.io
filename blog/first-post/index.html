Hugo와 Rewired로 블로그 시작하기

Nine // 2026-11-05 // 50 words // 1 min

Windows에서 Hugo와 Rewired를 처음 구성한 당시의 기록입니다. 자동 수집 뉴스가 아닙니다.

목차

  1. 오늘 한 작업
  2. 실행 명령어
  3. 앞으로 할 작업

블로그 구축 기록 · 자동 수집 뉴스나 수업 실습 프로젝트가 아닙니다. 아래 내용은 최초 작성 당시의 기록으로 보존합니다.

오늘 한 작업

Windows에서 Hugo Extended를 설치하고 Rewired 테마를 적용했다.

실행 명령어

hugo server -D

브라우저에서 http://localhost:1313/에 접속해 블로그를 확인한다.

  • GitHub 저장소 연결
  • GitHub Pages 배포
  • Google Analytics 연동
